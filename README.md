# ExpenseTracker

Учебный проект по дисциплине «Проектирование и разработка бизнес-ориентированного программного обеспечения».

## Бизнес-задача

Учёт доходов и расходов малого бизнеса: ведение операций по категориям, расчёт баланса, визуализация структуры расходов и доходов, синхронизация данных с облаком.

## Возможности

* добавление и удаление доходов и расходов с категориями
* расчёт баланса (доходы минус расходы)
* графики: структура по категориям и динамика по месяцам
* синхронизация с облаком (Firebase Realtime Database, REST API)
* экспорт данных в CSV

## Используемые технологии

* Python 3.10–3.13
* Kivy: кроссплатформенный интерфейс
* matplotlib и Kivy Garden: графики
* Firebase Realtime Database (REST API): облачное хранение
* Git и GitHub: контроль версий

## Инструкция по запуску

macOS / Linux:

```
python3 -m venv venv
source venv/bin/activate
pip install kivy matplotlib kivy_garden.matplotlib
python main.py
```

Windows:

```
python -m venv venv
venv\Scripts\activate
pip install kivy matplotlib kivy_garden.matplotlib
python main.py
```

Запускать как обычный файл, не в Jupyter или Colab.

## Настройка облака

1. В Firebase создайте проект и Realtime Database.
2. На вкладке Rules разрешите чтение и запись (`".read": true`, `".write": true`) и нажмите Publish.
3. Впишите адрес базы в переменную `FIREBASE_URL` в начале файла `main.py`.

Кнопка «В облако» отправляет записи в базу, кнопка «Из облака» загружает их обратно. Без адреса базы приложение работает локально.
